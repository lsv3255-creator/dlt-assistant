# Phase 12 Task #46：多彩种工作流与足彩首期 MVP

## 用户目标

将单一大乐透网站升级为多彩种综合分析网站，先落地传统足彩“胜负彩14场 + 任选九”，并保持大乐透现有功能和自动任务不变。

## 本期实现

- 保存多彩种九步交付工作流和平台隔离契约。
- 首页增加彩种切换，新增独立足彩移动端页面。
- 以第26143期官方赛程为身份基准，录入14场完整赛程；公开平均欧指仅作为分析证据。
- 程序完成欧指归一化、14场五个双选、任选九九个单选、注数和金额计算。
- 在线免费 AI 输出综合判断、14场取舍、任选九取舍和风险；失败时明确显示更新中。
- 预留并实现正式赛果到达后的冻结方案命中复盘。
- 新建独立 `football-analysis.yml`，不调用大乐透 scheduler/publisher。
- 客户页隐藏模型、版本、哈希、生成时间、缓存和后台错误。

## 当前边界与下一步

第一阶段的赛程和市场数据先采用经人工核验的当前期数据；自动任务负责反复生成 AI 文案和赛后复盘。下一小步是增加“官方最新公告自动发现 + 场次调整检测 + 新期首写冻结”，通过后才能取消人工期号核验。数据不完整时必须停发，不允许自动猜测。

## 验收标准

1. 第26143期14场身份、停售时间和官方公告一致。
2. 14场方案恰有五个双选，共32注、64元；任选九恰选9场。
3. 概率逐场归一化，结算只使用冻结选择。
4. 足彩页面无后台运行元数据。
5. 足彩 workflow 与大乐透 workflow 无写入交叉。
6. 全量现有测试继续通过，正式域名手机端可访问。
