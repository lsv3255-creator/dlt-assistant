## 单一最终推荐原则（Phase 9-C）

**决策日期**：2026-08-21
**决策内容**：大乐透 AI 推荐系统采用「单一最终推荐」原则
**理由**：
- 普通用户只需要一个明确的「下一期 AI 综合推荐」号码
- 避免多个推荐方案造成选择困难
- 符合「娱乐分析、选号辅助」的产品定位
**状态**：生效中

**核心架构**：
1. **后台允许多模型并行**：热度模型、冷热模型、遗漏模型、趋势模型、结构模型、回测模型可同时运行
2. **所有模型只作为内部计算层**：禁止直接输出多个推荐方案给用户
3. **新增最终推荐层**：综合评分 + 权重融合 + 历史回测验证 → 生成唯一 final_recommendation
4. **前端产品原则**：普通用户页面只能展示一个最终推荐号码组合
5. **推荐更新机制**：开奖完成后重新分析 → 生成下一期唯一推荐 → 更新前端

**实施要点**：
- `recommendation_new.json` 保持「1 主 +2 备」格式（主推荐为 final_recommendation）
- 后台多模型计算结果写入 D1 数据库的 `dlt_analysis`、`dlt_scores`、`dlt_recommendations` 表
- 前端仅读取并展示 final_recommendation 字段
