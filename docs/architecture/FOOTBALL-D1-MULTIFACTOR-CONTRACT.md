# 足彩当前期数据库与多因素分析契约

## 目标

足彩与大乐透共用 Cloudflare D1 基础设施，但使用完全独立的表、API、生成脚本和自动任务。足彩只保存当前在售/刚结算期的可复现分析快照，不建设长期赛果、比分或开奖历史库。

## 数据边界

- `football_current_snapshot`：前端可直接使用的当前期公开快照，固定单例 `slot=1`。
- `football_current_matches`：当前14场的身份、排名、指数、综合相对概率、因素覆盖和冻结选择；每次写入先清空旧期。
- `football_current_analysis`：当前期14场/任选九方案、AI中文解释和聚合复盘。
- 禁止新增足彩长期赛果/比分历史表；复盘只保存当前冻结方案的命中汇总，不保存历史比分序列。
- 大乐透既有 `dlt_*` 表、算法、工作流和公开文件不受影响。

## 因素与降级

当前可核验输入为市场平均欧指、同联赛排名和主客场身份；市场分歧用于复式覆盖及任选九筛选，数据完整度用于披露证据覆盖。近期状态、伤停、休息天数和历史交锋在没有可靠结构化来源时明确标记为未使用，AI不得补造。

综合相对概率是因素比较结果，不是真实胜率，也不承诺中奖。若排名缺失，引擎只用仍可核验的市场与主客场信息，并在因素覆盖中明确降级。

## 发布与回滚

独立足彩任务依次生成快照、运行测试、幂等建表、写入明细，并在最后切换公开快照、提交静态备份和部署。这样写入中途失败时API仍提供上一份完整快照。页面优先请求 `/api/football-current`，接口失败时读取原有静态 JSON。回滚可直接 revert 本任务提交；静态读取路径仍然存在。
